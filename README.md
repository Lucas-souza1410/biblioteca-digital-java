# Sistema de Gerenciamento de Biblioteca Digital

📅 **Projeto desenvolvido originalmente:** **06/2025**

🎓 **Disciplina:** Programação Orientada a Objetos – FMU

📤 **Publicado no GitHub:** 07/2026

---

## Sobre

Projeto desenvolvido como Atividade Prática Supervisionada (APS) da disciplina de Programação Orientada a Objetos da FMU.

O sistema simula o gerenciamento de uma biblioteca digital, permitindo o cadastro de usuários, livros, revistas e DVDs, além das operações de empréstimo e devolução de itens. O projeto foi desenvolvido para aplicar os principais conceitos da Programação Orientada a Objetos em Java.

## Tecnologias

- Java
- Programação Orientada a Objetos (POO)
- ArrayList

## Conceitos aplicados

- Encapsulamento
- Herança
- Polimorfismo
- Abstração
- Classes Abstratas
- Coleções (`ArrayList`)

## Funcionalidades

- Cadastro de usuários
- Cadastro de livros
- Cadastro de revistas
- Cadastro de DVDs
- Empréstimo de itens
- Devolução de itens
- Simulação do sistema através da classe `Main`
